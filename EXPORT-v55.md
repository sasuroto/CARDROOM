- Исходный коммит Sites: `a7cb36be8ac47f512505ac4d9d1eb5d3e62984ba`.
- Сайт: https://cardroom-europe.lush-flute-9375.chatgpt.site
- Экспорт содержит все **222 отслеживаемых файла** этого коммита без изменений, плюс этот документ и манифест экспорта.
- Это экспорт кода v55, не v52. Он не перепубликовывает сайт и не включает автоматическую синхронизацию GitHub с Sites.

## Требования и установка
Node.js >=22.13.0, npm, Git и доступ к сети для загрузки зависимостей.
Проект использует React, TypeScript, Vinext/Vite и Cloudflare Workers; это не статический HTML-сайт.

```sh
git clone https://github.com/sasuroto/CARDROOM.git
cd CARDROOM
node scripts/install-pnpm-portable.mjs
npm run dev
```

Репозиторий приватный: для клонирования нужен доступ GitHub.
Установщик использует зафиксированный pnpm 11.25.0 и `pnpm-lock.yaml`.
Откройте адрес, напечатанный сервером; для чистого portable-клона порт по умолчанию 5173.
Не копируйте из другой среды `node_modules`, `.sites-runtime` или `.wrangler`.

## Проверки

```sh
node tests/weather.cjs
node tests/aemet-weather.cjs
```
Для экспортируемого коммита выполнены успешно: 49 weather assertions и 19 AEMET/appointment checks.

## Сборка и локальный просмотр
```sh
npm run build
npm start
```
`npm start` запускает собранный Worker локально через Wrangler. Адрес и порт смотрите в выводе.
Сборка v55 была успешно выполнена перед её публикацией. Эти команды не публикуют сайт.

## Что сохранено
- `app/`: страницы, компоненты матчей, календарь, стили и API.
- `components/`, `hooks/`, `public/`, `vendor/`: интерфейс, ресурсы и лицензии.
- `lib/`: модели статистики, источники, парсеры, погодные интеграции и исходные JSON-срезы.
- `tests/`: тесты и фикстуры.
- `build/`, `scripts/`, конфигурация TypeScript/Vite, package.json и lockfile.
- `.openai/hosting.json`: исходная конфигурация Sites v55 с R2 binding `BUCKET`; D1 не используется.

API сохранены: `/api/analysis`, `/api/data`, `/api/match`, `/api/matches`, `/api/referees`, `/api/standings`, `/api/team`, `/api/weather`.
Погодный код включает Open-Meteo, резервный MET Norway и специализированный AEMET-сценарий из v55. Обработка отсутствующих значений, временных ограничений источников и сохранённых прогнозов сохранена.

## Данные и размещение
В экспорт входят JSON-срезы, отслеживаемые Git. Текущий production-кэш и результаты обновлений в R2 находятся отдельно на сервере и **не являются частью этого экспорта**. Локальная среда использует отдельное хранилище Miniflare.
Доступность свежих данных зависит от внешних источников; ответы 403/429 и неполные данные возможны.
Расписания ChatGPT/Sites, права доступа, runtime-секреты и инфраструктура production не переносятся Git-клонированием.
Экспорт не содержит токенов доступа для развёртывания. Для отдельного production-хостинга нужны собственная конфигурация Cloudflare Workers/R2 и отдельное расписание обновлений.
Не используйте production project_id для случайной публикации копии: исходный файл сохранён ради точности экспорта.
